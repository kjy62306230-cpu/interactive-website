# MORK.md — MØRK 사이트 영구 스펙 (source of truth)

> Claude Code가 매 세션 자동으로 읽는다.
> 가상의 프리미엄 무선 이어버드 브랜드 **MØRK(모르크, 덴마크어 "어둠")**.
> 목적 = **인스타 릴스 홍보용 시네마틱 원페이지 랜딩**. 내부 구성보다 "이목 끌기"가 1순위.

---

## 0. 목표 / 톤

- **다크 시네마틱 · 원페이지 · 인스타 후킹용.** 스크롤마다 새 연출이 터진다.
- 레퍼런스 무드: horyx.studio, 로지텍/소니 AI 광고, Antigravity 류 — **다크 배경 + 제품 회전 + 빅 세리프 타이포 겹침 + 절제된 파티클**.
- 핵심 원칙: **이미 완성된 히어로 스크럽이 심장.** 나머지 섹션은 그 톤을 깨지 않고 확장.

---

## 1. 기술 스택

- **HTML + CSS + Vanilla JS** (프레임워크 없음, 빌드 스텝 없음)
- 스크롤 스크럽 = **이미지 시퀀스 + canvas drawImage + lerp 스무딩** (검증된 방식. 영상 currentTime 스크럽 금지)
- 부드러운 스크롤: Lenis 권장 (없어도 동작)
- 파티클·글로우·비네트 = **canvas 2D 직접 그림** (외부 라이브러리 0)
- 정적 사이트. 원페이지 (스크롤만, 섹션 점프 내비만)

---

## 2. 컬러 / 타이포 (CRITICAL)

```css
:root{
  --ink:    #050506;  /* 베이스 (거의 검정) */
  --panel:  #0d0d0f;  /* 섹션 배경 변주 */
  --metal:  #c9c4bd;  /* 메탈 텍스트/강조 */
  --fog:    #6e6a64;  /* 보조 텍스트/라벨 */
  --accent: #e8e3da;  /* 메인 텍스트 (오프화이트) */
  --spark:  #ffffff;  /* 파티클 */
}
```

- **디스플레이**: Cormorant Garamond (라이트 weight, 큰 에디토리얼 스케일, 이탤릭 강조)
- **라벨/본문**: Inter (대문자 라벨은 자간 0.3~0.42em)
- 순수 흰 배경 금지. 골드 UI 금지. 네온/보라 그라데 금지. 핑크 금지.
- 톤은 **여백 · 스케일 · 모션 · 빛**으로 만든다 (색 절제).

## 5. 섹션 스펙 (원페이지 5섹션 + 푸터)

### NAV (고정·미니멀)
- 좌: MØRK 워드마크 / 우: Sound · Tech · Buy (섹션 앵커)
- 스크롤 시 배경 살짝 어두워지는 정도. 과한 효과 금지.

### [1] HERO ★ (이미 완성 — 그대로 이식)
- 히어로 시퀀스 스크럽(분해→합체→도킹→닫힘→회전)을 canvas로 스크럽.
- **가장자리 radial mask 페더링** → 배경에 녹아듦.
- 전역 배경: **거의 검정 + 중앙 포커싱 스포트 + 강한 비네트 + 흰 파티클(글로우)**.
- 빅 세리프 타이포 레이어: 인트로 거대 `MØRK` → 좌/우 카피 → 엔딩 슬로건.
- **반응형 적응**: 세로(모바일)=영상 가로폭 꽉+카피 하단 / 가로(PC)=영상 높이기준+좌우 여백에 빅타이포.
- lerp 스무딩으로 "확! 스크롤해도" 부드럽게. 분해·결합 구간은 모션보간으로 더 촘촘(느리게).
- ※ 검증된 데모 코드가 별도 존재 → 그 로직을 모듈화해서 이식.

### [2] STATEMENT
- `--ink` 배경. 대형 Cormorant 세리프 한 줄 "Sound, assembled." + 넉넉한 여백.
- 단어 단위 클립업 리빌.

### [3] SPEC SCROLL
- 분해(익스플로디드) 이미지 핀 고정 + 스크롤 따라 스펙 텍스트가 부품 옆에 하나씩 리빌.
- 항목: Driver / Battery 60mAh / Bluetooth 5.3 / Brushed metal housing.
- 라인으로 부품-텍스트 연결(미세).

### [4] GALLERY
- 제품 컷 가로 스크롤(또는 그리드): 정면·측면·열림·뒷면.
- 커서 틸트 + 호버 디테일(절제).

### [5] CTA
- 닫힌 케이스 회전 클립(또는 정지컷 회전) + "Experience MØRK" 마그네틱 버튼.

### FOOTER
- MØRK 워드마크 · 소셜(IG) · © 2026. 미니멀.
